# Output Directory

This directory contains all output files generated by the pipeline.

## Structure

```
output/
├── tiles/          # Tiled images from step 1
├── geojson/        # GeoJSON files with predictions
├── final/          # Final merged results
│   └── tree_crowns.gpkg
└── pipeline.log    # Execution log
```

## Files

- **tiles/**: Individual tile images and their predictions
- **geojson/**: Georeferenced predictions in GeoJSON format
- **final/**: Final merged and cleaned tree crown polygons in GeoPackage format
- **pipeline.log**: Detailed execution log with timestamps

## Cleanup

To clean all outputs and start fresh:
```bash
# Windows
Remove-Item -Recurse -Force output\*

# Linux/Mac
rm -rf output/*
```

Note: This directory is excluded from Git (except README and structure).
